# Lan-Flow Project

Lan-Flow is a modern client management system inspired by the workflows of traditional Brazilian lan houses. It combines efficient user authentication, client registration, and session tracking to deliver a streamlined management experience.

## Table of Contents

- [Overview](#project-overview)
- [Technologies Used](#technologies-used)
- [Roadmap](#project-roadmap)

## Project Overview

Lan-Flow leverages the power of modern web technologies to reimagine client management for today's needs. Inspired by the operations of Brazilian lan houses, the system provides robust features like user authentication, client registration, and session management.

## Technologies Used

- **Next.js**: Frontend framework for building a modern and scalable web application.
- **NextAuth.js**: Authentication library for secure user login and session management.
- **Prisma**: ORM (Object-Relational Mapping) for seamless integration with MongoDB.
- **MongoDB**: NoSQL database for storing user and session data.

## Project Roadmap

### Completed Tasks

#### 1. Skeleton Creation

- Built the foundational project structure using **Next.js**.
- Established the main application routes:
  - `/`: Homepage (requires user authentication)
  - `/login`: User login page
  - `/cadastro`: User registration page

#### 2. Third-Party Integrations

- Integrated **NextAuth** for secure and efficient user authentication and session handling.
- Configured **Prisma** and **MongoDB** for database operations, including reading, writing, and updating user data.

# Projeto Lan-Flow

O Lan-Flow é um sistema moderno de gestão de clientes inspirado no fluxo de trabalho das tradicionais lan houses brasileiras. Ele combina autenticação de usuários, registro de clientes e rastreamento de sessões para oferecer uma experiência de gestão eficiente.

## Visão Geral do Projeto

O Lan-Flow utiliza tecnologias web modernas para reinventar a gestão de clientes de maneira eficiente e atual. Inspirado no funcionamento das lan houses brasileiras, o sistema oferece funcionalidades robustas, como autenticação de usuários, registro de clientes e gerenciamento de sessões.

## Tecnologias Utilizadas

- **Next.js**: Framework para criação de aplicações web modernas e escaláveis.
- **NextAuth.js**: Biblioteca de autenticação para login seguro e gerenciamento de sessões.
- **Prisma**: ORM (Object-Relational Mapping) para integração com o banco de dados.
- **MongoDB**: Banco de dados NoSQL utilizado para armazenar dados de usuários e sessões.

## Roadmap do Projeto

### Tarefas Concluídas

#### 1. Criação do Esqueleto

- Desenvolvida a estrutura inicial do projeto utilizando **Next.js**.
- Estabelecidas as principais rotas da aplicação:
  - `/`: Página inicial.\*
  - `/login`: Página de login de usuários.
  - `/cadastro`: Página de registro de novos usuários.\*

#### 2. Integrações Third-Party

- Integrado o **NextAuth** para autenticação de usuários e gerenciamento de sessões de forma segura.
- Configurado o **Prisma** e o **MongoDB** para operações no banco de dados, incluindo leitura, gravação e atualização de dados de usuários.

###### Obs: rotas marcadas com \* possuem autenticação obrigatória.
